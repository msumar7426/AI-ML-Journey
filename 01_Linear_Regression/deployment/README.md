# Karachi Car Price Estimator (Frontend)

A small Streamlit app that puts a real form in front of the trained model from `../project/used_car_price_prediction.ipynb`: pick a manufacturer, variant, year, mileage, engine size, fuel type, and transmission, and get back an estimated listing price in PKR.

Run it locally (see below) to see it live, plain editorial styling, cream background, single dark accent, no gradients.

## Why Streamlit, and why local/free hosting

Hugging Face Spaces moved to a paid tier for anything beyond the smallest free CPU instance, and most other hosts that make sense for a small ML demo (Render, Railway) either charge or spin the app down aggressively on their free tiers. Streamlit Community Cloud (`share.streamlit.io`) is still free for public apps connected to a public GitHub repo, with no spend limit and no time-boxed trial, so that is the deployment path below. Running it locally is also fully supported and takes one command.

## Files

```text
01_Linear_Regression/
  project/                used_car_price_prediction.ipynb, the raw CSV, notes/
  deployment/              this folder
    app.py                 the Streamlit app itself
    train.py               rebuilds model.joblib/scaler.joblib/meta.json from the raw CSV
    model.joblib           the trained scikit-learn LinearRegression model
    scaler.joblib          the fitted StandardScaler (year/mileage/engine)
    meta.json              feature column layout, dropdown options, manufacturer-to-variant map
    requirements.txt       exact package versions used to train and test this app
    README.md              this file
```

`deployment/` is a sibling of `project/`, not nested inside it: `project/` is the analysis (notebook, data, notes), `deployment/` is the app built from it. Future projects in this repo should follow the same pattern.

`model.joblib`, `scaler.joblib`, and `meta.json` are already built and committed, generated by running `train.py` once against the project's CSV. The app never re-trains anything at runtime, it just loads these three files and predicts.

## Run it locally

```bash
cd 01_Linear_Regression/deployment
pip install -r requirements.txt
streamlit run app.py
```

Opens at `http://localhost:8501`.

## Deploy for free on Streamlit Community Cloud

1. Push this repository to GitHub (it already needs to be public, or Community Cloud needs access to the private repo).
2. Go to `share.streamlit.io` and sign in with GitHub.
3. Click "New app", pick this repository and branch.
4. Set the "Main file path" to `01_Linear_Regression/deployment/app.py`.
5. Deploy. The first build installs `requirements.txt` and takes a minute or two; after that the app has a permanent public URL, free, with no trial period.

If the repository is private, Community Cloud can still deploy it after you grant it access to that specific repo during setup.

## Regenerating the model artifacts

If the notebook's cleaning or feature engineering steps change, rerun `train.py` (from inside this folder) to regenerate `model.joblib`, `scaler.joblib`, and `meta.json`. `train.py` mirrors Stage 2, Stage 4, Stage 5, and Stage 6 of the notebook exactly, confirmed by checking its test R2 (0.9226) matches the notebook's.

## Limitations

Same as the notebook: trained on Karachi listings only, from December 2025, predicting asking price rather than confirmed sale price. The "typical error" shown under a prediction is the model's MAE on held out test data, expressed as a percentage of the predicted price, not a guarantee.
